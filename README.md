# Portfolio — Quach Trong Nhan

Personal site for a Front-End Developer. Built with React 19, TypeScript, Vite, and Tailwind CSS. Content comes from the CV and lives in `src/data/portfolio.ts`.

## Chạy local

```bash
npm install
npm run dev
```

Mở địa chỉ Vite in ra (thường là http://localhost:5173).

## Build

```bash
npm run build
npm run preview
```

## CV tải về

Đặt file PDF tại `public/cv.pdf`. Nút **Download CV** trỏ tới `/cv.pdf`.

## Deploy

Có thể đẩy thư mục này lên Vercel hoặc Netlify. Build command: `npm run build`. Output: `dist`.
